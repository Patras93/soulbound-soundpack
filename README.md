# Soulbound Soundpack v1.6.8

Natywny soundpack Lua dla Generic MUD v0.24.0+ i Soulbound v116.00.43. Zachowano **87 OGG**.

**Naprawa zmiany strefy:** Rozbudowane lokacje v116.00.43 często zgłaszają samo "Docierasz do" bez późniejszego LOOK. Soundpack korzysta teraz ze sprawdzonego katalogu 295 fizycznych granic na 141 strefach (20 081 lokacji) i gra events/change area.ogg po potwierdzonym wejściu do innej strefy. Nie odtwarza dźwięku przy każdym kroku ani ponownie po LOOK.

Katalog przejść jest oparty na v116.00.43. Zmiany sieci przejść w kolejnych wersjach mogą wymagać jego aktualizacji.

**Aktualizacja:** Generic MUD > Soundpacks > Manage installed soundpacks > Update from source, potem ponowne połączenie.

**Publikacja:** GitHub Actions automatycznie buduje i publikuje ZIP przy zmianie pack.toml, bez CMD/BAT.
